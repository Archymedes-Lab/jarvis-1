Pair this browser

ARGUS-INSTINCT shows your security data only to browsers you have paired. The quickest way:

  1. Open the ARGUS-INSTINCT app on this computer.
  2. Press Ctrl K and choose Open in your browser, or use the button in Settings.
  3. This browser pairs by itself. Links work once and expire after two minutes.
No app? Pair with a token instead

Quickest from a terminal on the machine running ARGUS-INSTINCT: jarvis desktop browser opens a one-time link like the app does.

Or run jarvis desktop pair --name browser (under its own account: sudo jarvis-svc desktop pair --name browser) and paste the token it prints.

The pairing is kept as a cookie page scripts cannot read. See or remove paired browsers with jarvis desktop clients and jarvis desktop revoke ID.
