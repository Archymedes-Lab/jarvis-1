# Reporting security issues

Report suspected vulnerabilities privately to support@archymedes.xyz with the
subject “ARGUS-1 security report”. Do not include credentials, private evidence
or personal data. Start with affected version/commit, impact and minimal
synthetic reproduction steps. Arrange a protected channel with the maintainers
before sending sensitive material. Do not attach live user databases or logs
to public issues. No encrypted-mail key or response-time guarantee is asserted.

The maintainers coordinate fixes and disclosure with reporters. There is no
promised bounty. Test only systems you own or are authorized to test. Preserve
evidence, use isolated synthetic fixtures and avoid destructive experiments.

This is early-stage security software. Supported patch versions and shipped
fixes must be confirmed in release notes; no long-term support period is
promised here. Collector health, assurance scores and replay benchmarks are
not compromise verdicts or guarantees. See the
[Maximum Assurance directive](docs/security/MAXIMUM-ASSURANCE.md),
[architecture](docs/architecture/DEFENDER-ENGINE.md) and
[reproducible evaluations](docs/open-source/EVALUATIONS.md).
